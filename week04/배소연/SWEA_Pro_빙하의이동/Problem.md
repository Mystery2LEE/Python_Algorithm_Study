## 바다
- N * N 크기
- 좌상단 좌표 (0, 0) (Y축, X축) 순서
- 바다의 왼쪽 끝과 오른쪽 끝은 서로 인접 / 바다의 위쪽 끝과 아래쪽 끝도 서로 인접
    - 즉 (0, 0)의 왼쪽에는 (0, N-1) 존재, (0, 0)의 위쪽에는 (N-1, 0) 존재
    - 한마디로, 구 형태라고 볼 수 있음


## 빙하
###정의
상하좌우로 다른 얼음과 인접한 얼음들

### 크기
- 면적: 하나의 빙하를 이루는 얼음의 개수
- 부피: 하나의 빙하를 이루는 모든 얼음의 높이의 합
- 위치: 빙하의 최상단 행, 좌측 열에 위치한 얼음의 좌표


### 빙하의 action
#### 융해
- 바다와 인접한 빙하를 구성하는 얼음의 높이가 1씩 줄어듦
- 높이가 0이 될 경우, 얼음은 사라짐
- 융해에 의하여 빙하는 2개 이상의 빙하로 나누어질 수 있음
- 빙하가 나누어지더라도, 각 빙하의 이동방향은 변하지 않음

#### 이동
- 빙하가 상하좌우 중 한 방향으로 1칸씩 이동 (매 년)
- 모든 빙하는 동시에 이동
- 초기 이동 방향은 입력으로 주어짐

#### 병합
- 다른 빙하가 서로 충돌하거나, 상하좌우로 인접할 경우 하나의 빙하가 됨
- 서로 다른 빙하를 구성하는 얼음이 같은 좌표에 겹칠 경우, 높이가 높은 얼음만 그 자리에 남음
- 병합된 빙하는 이동 방향이 바뀜 -> 각 빙하의 이동 전 상태를 비교해 병합 후 이동방향 결정
    1. 부피가 큰 빙하의 이동 방향을  따름
    2. 부피가 같을 경우, 면적이 작은 빙하의 이동 방향을 따름
    3. 면적이 같을 경우, 두 빙하의 위치 중, Y좌표가 작은 위치에 있는 빙하의 이동방향을 따름
    4. Y 좌표가 같을 경우, 두 빙하의 위치 중 X 좌표가 작은 위치에 있는 빙하의 이동 방향을 따름
